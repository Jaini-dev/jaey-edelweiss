🔐 Admin Access
Admin access is controlled via the Team tab.
Any team member with the ADMIN role can log in on the Admin tab using their own PIN.

To add a new admin: go to Team tab → Add member → Role: Admin.
To promote an existing member: Team tab → Make admin.
