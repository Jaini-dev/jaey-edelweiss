▸ How to get the Azure Client ID (5 min, free)
  1. Go to portal.azure.com → search App registrations → New registration.
  2. Name it Jaey Tasks. Under Supported account types choose Accounts in any org directory and personal Microsoft accounts.
  3. Under Redirect URI, pick platform Single-page application (SPA) and paste the URI shown above.
  4. Click Register. Copy the Application (client) ID and paste it in the box above.
  5. Open API permissions → Add → Microsoft Graph → Delegated → add Calendars.ReadWrite and User.Read.
  6. Done — everyone now signs in with Microsoft, and deadlines sync to their calendars automatically.
